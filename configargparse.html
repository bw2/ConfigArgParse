def parse_toml_section_name(section_name): (source) ¶

Parse a TOML section name to a sequence of strings.

The following names are all valid:

"a.b.c"            # this is best practice -> returns ("a", "b", "c")
" d.e.f "          # same as [d.e.f] -> returns ("d", "e", "f")
" g .  h  . i "    # same as [g.h.i] -> returns ("g", "h", "i")
' j . "ʞ" . "l" '  # same as [j."ʞ"."l"], double or simple quotes here are supported. -> returns ("j", "ʞ", "l")

def _convert_parsed_value_to_config_file_value(action, value): (source) ¶

Convert a parsed arg value to the value a config file should hold for it.

For a flag (store_true, store_false, store_const or append_const), the config file value says whether to invoke the flag, not what it stores, so it is "true" exactly when the parsed value is (or, for append_const, holds) the one the flag stores. Other booleans are written in lowercase too, so values from the command line and from environment variables are written the same way. A tuple for an option that takes a list of values, such as a default of (640, 480) for nargs=2, is written as a list.

Values of other types, such as a pathlib.Path default, are written as str(), since every config file format can write a string and read it back. (Such a value that argparse made from a string has already been replaced with that string, see ArgumentParser._replace_parsed_values_with_the_strings_they_came_from().)

Parameters
actionthe action the value was parsed for.
valuethe value the parser stored for the action.
Returns
object"true" or "false" for flags and booleans, otherwise the value with anything that isn't a str, int, float, bool or list converted to a str.
def _convert_to_types_every_config_file_parser_can_write(value): (source) ¶

Convert a value to a plain str, int, float, bool or list of those.

An Enum member is written as its value, which is what a type= callable like type=SomeEnum takes back (one that takes its name instead has already been given the name, see _replace_enum_members_its_type_reads_by_name_with_their_names()). Some config file writers only handle the built-in types themselves, so a subclass of one (eg. a str or int Enum's value, or an IntEnum) becomes that built-in type, and anything else becomes a str.

Parameters
valuea parsed arg value, or an element of a list value.
Returns
objectthe value, with each list element converted the same way

Check whether a default can be written to a config file and read back.

It can when it is a str, int, float, bool, Enum or path, or a list or tuple of these that isn't empty. Read back, an empty list sets an option to no values, which argparse rejects for nargs='+', and str() of other objects, such as the open file in a default of sys.stdout, isn't anything the option's type= can take.

def _quote_ini_value_if_needed_to_read_back_unchanged(value): (source) ¶

Write a string the way IniConfigParser.parse() reads back unchanged.

parse() strips the whitespace around a value, skips an empty one, reads a value in square brackets as a list and one on several lines as a list (if split_ml_text_to_list is set), and unquotes a quoted one. A list element written on a line of its own that starts with '#' or ';' would be read as a comment. A value any of that would change is written as a Python string literal, which parse() unquotes back to the same string.

Parameters
valuethe string to write.
Returns
strthe value, or its Python string literal

def _replace_enum_members_its_type_reads_by_name_with_their_names(action, value): (source) ¶

Write an Enum member as its name where the action's type= needs that.

An Enum member is otherwise written as its value (see _convert_to_types_every_config_file_parser_can_write()), which suits type=SomeEnum, but not a lookup by name such as type=lambda s: SomeEnum[s]. So a member that the type= callable doesn't read back from its value, but does from its name, is replaced with its name.

Parameters
actionthe action the value was parsed for.
valuea parsed arg value, or an element of a list value.
Returns
objectthe value, with each such member replaced by its name
